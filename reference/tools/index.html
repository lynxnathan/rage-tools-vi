    Tools¶

    Every script in tools/ at a glance. The summary column comes from each file's own docstring, so this page is generated, not maintained by hand:

    python3 tools/tool_index.py          # regenerate
python3 tools/tool_index.py --check  # verify the page matches the code

    Run any tool with --help for its arguments. Most read from the repository root so python3 tools/<name>.py works without arguments.
